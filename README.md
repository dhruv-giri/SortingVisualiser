# About:
A web-based application designed to visualize sorting algorithms through dynamic, real-time animations. This project helps users understand algorithm behavior, comparisons, and time complexity in an intuitive and interactive way.


# Live Demo:
https://dhruv-giri.github.io/SortingVisualiser/

- Engineered an interactive platform using HTML, CSS, and JavaScript to simulate algorithm execution visually.  
- Implemented 6 core sorting algorithms with step-by-step animations:
  - Bubble Sort  
  - Selection Sort  
  - Insertion Sort  
  - Merge Sort  
  - Quick Sort  
  - Heap Sort  

# Tech Stack:
- HTML  
- CSS  
- JavaScript  

# Key Features:
- Real-time sorting animations  
- Step-by-step algorithm execution  
- Interactive and responsive UI  
- Visual representation of comparisons & swaps
